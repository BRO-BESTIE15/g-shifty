
# G-Shifty

A 2D gravity-reversal platformer
built with Python and Pygame.

> Created as an entry for
> GitHub Game Off 2026.

### Theme: **SHIFT**

---

## About

A platformer where players can reverse
gravity to navigate opposing surfaces.

---


## Controls (possibly)

- A/D: Move
- Space: Jump
- Shift: Reverse gravity
- Esc: Pause
